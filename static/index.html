Context with accountability.

Frequency Graph is an independent public reference application created by Val Rukhaylo / Altru.dev for Graph Hacks 2026. Its FalkorDB traversals expose downstream dependency relationships.

All initial data is synthetic. Investigations are deterministic and read-only. There is no external AI model or real-world action execution. Authorization and independent observation are not yet implemented.
