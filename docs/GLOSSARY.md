# Frequency Graph terminology and standard terminology

These are related concepts, **not assertions of standards equivalence**.

| Project term | Related engineering concept |
| --- | --- |
| DDC | Design by contract; constraint-based verification |
| Frequency / FDDCRF-EVO | Policy-governed execution assurance |
| Authority Envelope | Scoped authorization context; capability constraints |
| Capability Lattice | Capability-based access control; permission ordering |
| Policy IR | Intermediate representation of security policies |
| Guardian | Policy enforcement point; reference monitor |
| Action Gateway | Controlled execution gateway; policy enforcement point |
| Reasoning Gateway | Decision mediation and provenance control |
| Credential Broker | Delegated credentials; secrets management |
| Independent Observation | Read-after-write verification; state reconciliation |
| Dual Receipts | Execution record plus independent observation |
| CounterexamplePath | Counterexample trace; violation witness |
| EDRG | Evidence-driven release qualification gate |
| Edge Sprint | Vertical-slice integration development |
| GTS | Proposed governance conformance tests (not a ratified standard) |
| Impact Simulation | Graph reachability and hypothetical change analysis |
| Graph Poisoning | Knowledge-base integrity attack |
| Provenance | Data lineage and source attribution |

The full application includes a machine-readable glossary with definitions; this document is the initial readable map.
